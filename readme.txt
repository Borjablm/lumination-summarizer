AI-powered content summarization with support for URLs, text, and PDFs. Generate structured summaries or visual mindmaps.

== Description ==

Lumination AI Summarizer provides AI-powered content summarization for WordPress. Use shortcode presets to create purpose-built tools on SEO pages: YouTube Summariser, Book Summary, PDF Summary, AI Mindmap, and more.

**Features:**

* Single shortcode with preset support (youtube, book, pdf, mindmap)
* Four input modes: URL, text, PDF upload, and auto (tabbed interface)
* Three output formats: sectioned summary, raw summary, visual mindmap
* Configurable summary length (short, medium, long)
* Integrated with Lumination Core for API access, analytics, and theming

**Requires:** Lumination Core (v1.0.0+)

== Installation ==

1. Install and activate Lumination Core.
2. Upload the plugin zip via Plugins > Add New > Upload Plugin.
3. Activate the plugin.
4. Use `[lumination_summarizer]` or a preset like `[lumination_summarizer preset="youtube"]` on any page.
